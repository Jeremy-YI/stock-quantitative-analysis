## 数据核实（2026-08-29 实测，不是估算）

用「只读文件头尾 4 字节」的方式扫了全部 hsjday 个股文件（`SymbolKind.STOCK` 分类）：

| 项 | 实测值 |
|----|--------|
| 个股 .day 文件总数 | **6135**（沪深 5546 + 北交所 589） |
| 沪深里首个交易日 < 2020-01-01 | 3870 只（占沪深 **69.8%**） |
| 北交所里首个交易日 < 2020-01-01 | **0 只**（全部 2020 年后才有数据） |
| 文件末日 = 2026-08-28（仍在交易） | 5207 只（沪深） |
| 沪深「末日落在 2020-01-01 ~ 2026-08-01」= 期间内停止更新 | **225 只**（退市/长期停牌，**本地数据仍保留**） |
| 沪深「末日 < 2020-01-01」= 2020 年前就退市 | 110 只 |
| 北交所 241 只末日 = 2025-09-30 | **数据源缺口**（不是退市），北交所日线 2025-10 起没再更新 |

**与任务描述里「85% 在 2020-01-01 之前就有数据」的差异**：实测沪深是 69.8%，全体（含北交所）
是 63.1%。差异来源是分母里含了 2020 年后上市的 1676 只沪深新股 + 589 只北交所标的。
照实记录，不套用 85%。

**幸存者偏差的第一个好消息**（详见报告 §5）：本地数据**保留了 225 只期间内退市/停牌的沪深个股**，
不是纯「当前成分」快照。逐季度初有数据的股票数与公开上市家数对比放在报告里。

## 关键口径决定（写死，避免后续漂移）

1. **主宇宙 = 沪深 A 股（排除北交所）**。理由：①北交所标的 2021-11 之前是新三板，
   流动性与定价机制不可比；②本地北交所数据 2025-09-30 后断更。含北交所的版本作稳健性对照。
2. **每只股票读全历史**（不是尾部 N 根），指标用全历史算（与阶段 13/14 的「MACD 必须全历史」一致）。
3. **信号日要求至少 120 根前置 K 线**（覆盖 LT_RAW 的 MA114），基线用同一约束的股票-日集合。
4. **不套用 `should_include` 的停牌过滤**：阶段 12/13/14 走 `load_universe`，
   `suspension_days=20` 会把「末日早于窗口末 20 天」的退市股整只剔掉；本阶段保留它们
   （信号在数据断掉那天自然终止），以减轻幸存者偏差。差异量化见报告。
5. **复权**：主口径前复权（`market.adjust.forward_adjust_frame` 启发式），
   未复权作对照。阶段 12/13/14 全部是**未复权**（`load_universe` 不复权），
   所以未复权口径才是与前几阶段可比的那一版。
6. **为什么不用逐日扫描器**：深水单针是「每只股票只依赖自己历史」的纯函数规则，
   不需要 `DaySliceView` 的逐日全市场切片。改成**逐股一次算全序列 + 向量化前向收益 + 季度 bincount**，
   内存 O(单只股票)，速度快一到两个数量级（实测全程 ~6 分钟 vs 估算 90 分钟）。
   等价性用阶段 14 组1 的四段数字回归校验（任务 2）。
