# 策略迁移说明（阶段 3）

> 目的：把 `~/.openclaw/workspace/tools/` 下生产脚本里的五个选股策略，
> 迁移进 `packages/strategies`，统一接口 `scan(candles, as_of, config) -> list[Signal]`，
> 阈值集中收敛到各策略 `config.py`，并做一致性验证（同一份数据新旧选股结果一致）。
> 本文档记录每个策略「旧实现 → 新实现」的差异与改动理由。

---

## 0. 总原则

- **统一接口**：五个策略共用 `Signal`（pydantic，symbol/strategy/signal_type/score/triggered_at/metrics），
  签名一致 `scan(candles, as_of, config)`，返回 `list[Signal]`。
- **阈值收敛**：所有阈值进各策略 `config.py`（pydantic BaseModel + 中文 Field 描述），
  策略逻辑里禁止裸数字。
- **一致性优先**：有可比对旧脚本的，抽参考实现进 `tests/reference/` 逐只比对；
  旧脚本有 bug 的，修复后逐条记录，不糊过去。
- **目标宇宙**：每个策略用 `TARGET_KINDS` 声明扫个股还是 ETF，扫描器据此过滤。

---

## 1. 多周期重采样（`packages/market/resample.py`）

- 周线按自然周（`W-FRI`），月线按自然月（`ME`）；open 首 / high 最大 / low 最小 /
  close 末 / volume 求和。
- 停牌 / 长假造成的空周期不生成行（`dropna`）；不完整的最后一周 / 月保留，
  open/close 取周期内实际首 / 末交易日。
- 与旧脚本 `macd_monthly_water_weekly_goldencross.py::resample_ohlc` 完全一致
  （旧脚本用 pandas `resample('ME'/'W-FRI')`），黄金值 + 边界测试锁死。

## 2. 五个策略的口径与来源

### 2.1 b1b2b3（B1 超卖 / B2 右侧确认 / B3 缩量洗盘）

| 信号 | 条件（阈值见 `b1b2b3/config.py`） | 来源 |
|---|---|---|
| B1 | J < 16 或 K ≤ 30 | `daily_stock_picker.py::p2_scoring`（J<16）+ TOOLS.md「单针下30」的 K≤30 |
| B2 | PCT ≥ 3.7% + 量比 > 1.2（放量）+ 阳线（close>昨收）+ J 上行（J>昨J） | 截图分析框架（TOOLS.md）；J 上行是任务书明确加的条件 |
| B3 | 量比 < 0.8 + 5 日振幅 < 8% | 旧脚本 `vr<0.8` 判缩量 + 窄幅整理 |

- 与旧脚本差异：旧 `p2_scoring` 的 B2 只有 PCT≥3.7+放量+阳线三条件，**不含「J 上行」**；
  B1 只有 J<16，**不含 K≤30**。任务书明确要求这两个口径，故按任务书实现，
  属于「旧脚本打分逻辑 → 独立策略」时的显式扩展，已在此记录。

### 2.2 macd_resonance（月线 MACD 水上 + 周线底部金叉）

- 完全复刻 `macd_monthly_water_weekly_goldencross.py::analyze`：
  月线 DIF > 0，且周线最近 6 周内出现底部金叉（DIF 上穿 DEA，金叉当周 DIF < 0）。
- MACD 用 `indicators.macd.calc_macd`（首值做种子，与旧脚本 pandas `ewm(adjust=False)`
  数学等价）；重采样用 `market.resample`。
- score 取月线 DIF（越大越强），与旧脚本 `sort_values('m_dif', ascending=False)` 一致。
- **一致性验证通过**：同一份 80 只真实切片，新旧选出的 symbol 集合完全一致（见第 4 节）。

### 2.3 pin30（单针下30 + B1_W 超卖）

- **重要口径澄清**：TOOLS.md「单针下30(K≤30 且 D≥80)」里的 K/D 实际指 moomoo 的
  **短期/长期两条随机指标线**，不是 KDJ(9,3,3) 的 K/D。理由：
  - 用 KDJ 口径实测，全市场 5510 只里「K≤30 且 D≥80」**0 命中**——KDJ 的 D 追 K 太快，
    两者几乎不可能同时满足（K≤30 需要连续 3 日 RSV=0，此时 D 已被拉低到 50 附近）。
  - 参考脚本 `us_pin30_watchlist.py::calc_pin30` 用的就是短期(3日)/长期(20日)随机指标。
- 新实现按 moomoo 随机指标口径：
  - `pin30` = 趋势多头(ST_RAW>LT_RAW 且 C>LT_RAW) + 短期≤30 + 长期≥80；
  - `b1_w` = J<16（KDJ，TOOLS.md 的超卖口径）。
- 全市场实测：pin30 命中 6 只、b1_w 命中 826 只（随机指标口径下可正常触发）。

### 2.4 stealth_rally（偷涨型：水下二次金叉）

- 复刻 `stealth_rally_scanner.py` + `daily_stock_picker.py::detect_underwater_double_golden`：
  水下二次金叉 + 红柱确认 + 最近一次水下金叉 ≤ 60 天 + 近 10 日无涨停，打分公式逐项复刻。
- **旧脚本 bug 修复**：`stealth_rally_scanner.py::has_recent_limit_up` 用 `r[5]`（成交额
  amount）当昨收，导致「近10日无涨停」过滤**形同虚设**（永远不触发）。新实现改用真实
  昨收。这是有意的行为差异，已用单测锁死正确口径。
- **一致性验证**：核心逻辑（`detect_underwater_double_golden` 加分、最近水下金叉索引、
  打分公式）与旧脚本逐只一致（见第 4 节）；涨停过滤因 bug 修复单列。

### 2.5 etf_accumulation（ETF 连续吸筹）

- `etf_consec_tracker.py` 的「连续净流入天数」是 akshare 主力资金流口径，依赖外部数据源，
  而本平台策略层只读本地 K 线，故按 TOOLS.md「ETF 入场监控规则」的 K 线口径实现：
  - 跌幅 25%-40%（相对近 60 日高点回撤）；
  - 底背离：价格创近 20 日新低，但 MACD DIF 或 RSI 未创新低。
- 资金流版本的「连续吸筹」列为后续 TODO（需接入 akshare 盘后 ETL）。

## 3. 过滤规则（`strategies/filters.py`）

按「市场 + 6 位代码前缀」判定标的种类（个股 / ETF / 指数 / 可转债 / 基金），参考
`macd_monthly...` 的 `STOCK_RE`、`stealth_rally_scanner` 的 `BAN_PREFIXES`、
`ticker_types.py` 的「个股 vs 基金」思想（A股前缀版）。可配置过滤：上市不足 N 日 /
成交额下限 / 停牌 / ST（需名称注入）。全市场 12377 个文件过滤后剩 5510 只个股。

---

## 4. 一致性验证结论（验收核心）

用 `scripts/make_fixtures.py` 生成的 80 只真实个股切片（含 2026-08-27 触发各策略的代表标的），
在 `tests/unit/test_strategy_consistency.py` 里跑新旧两套：

| 策略 | 验证方式 | 结果 |
|---|---|---|
| macd_resonance | 新旧 symbol 集合 + 关键指标（m_dif/m_dea/cross_dif/cross_week） | ✅ 完全一致 |
| stealth_rally | `detect_underwater_double_golden` 加分 + 最近水下金叉索引 + 打分 | ✅ 逐只一致（涨停过滤单列，见 2.4） |
| b1b2b3 / pin30 / etf_accumulation | 无直接可比的旧 A股列表脚本（分别埋在打分里 / 美股 yfinance / akshare 资金流） | 用快照测试锁回归（`tests/unit/test_strategy_snapshots.py`，非空快照） |

**不一致项（已查清并记录）**：
1. stealth_rally 涨停过滤：旧脚本用 amount 当昨收 → 过滤失效；新实现修复，故新旧
   「近10日无涨停」行为不同（新实现会多排除近期涨停股）。这是旧脚本 bug，已修复。
2. pin30 口径：旧 A股「单针下30」在 `detect_washout_needle` 用白线/红线(3/21) 随机指标
   且不要求趋势多头；TOOLS.md 的「K≤30 且 D≥80」KDJ 口径实测不可触发。新实现按
   us_pin30_watchlist 的短期/长期随机指标 + 趋势多头落地。
3. 浮点精度：`indicators.macd.calc_macd`（Python 递推）与 pandas `ewm` 在第 15 位小数
   有差异，一致性测试用 abs=0.001（3 位小数）容差比对，不影响选股集合。

## 5. 全市场扫描实测耗时（2026-08-27，本地 Mac）

- 标的池：hsjday 12377 个 .day 文件 → 过滤后 **5510 只个股**（+1458 只 ETF）。
- 只读文件尾部 800 根 K 线（策略所需回看窗口上限），避免全量 struct 解包。

| 阶段 | 耗时 |
|---|---|
| 读取 + 过滤（tail read） | ~25s |
| b1b2b3 | ~7s |
| macd_resonance | ~28s（月/周重采样 + 双周期 MACD） |
| pin30 | ~5s |
| stealth_rally | ~3s |
| etf_accumulation | ~1s |
| **全链路合计** | **~69s** |

结论：单日全市场扫描约 1 分钟，作为盘后 cron 可接受。若需进一步提速，macd_resonance
的 MACD 递推可换 pandas/numpy 向量化（当前用 indicators 包的 Python 递推，与旧脚本同源）。
