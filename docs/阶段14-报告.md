## 3. 第三步（最核心）：三条线作为洗盘判别器的价值检验

单针事件（short≤30）按三条线分两组，比前向收益差（Δ = 组A洗盘 − 组B破位，正=洗盘更优）：

### 3.1 组A(回踩不破=洗盘) vs 组B(已破2日=破位) 25 日收益差 Δ（pp）

| 线 | IS | OOS-A | OOS-B | OOS-C |
|----|----|-------|-------|-------|
| 生命线 | **-1.67** | **-1.26** | **-2.57** | **-2.00** |
| 阴量定价线 | **-1.72** | **-0.89** | **-2.09** | **-1.81** |
| 进攻K防线 | -3.81 (B组 n=0) | -0.78 (n=0) | +2.23 (n=0) | +4.06 (n=0) |
| 任一不破 | **-2.16** | **-1.53** | **-2.85** | **-2.13** |
| 全部不破 | **-1.67** | **-0.95** | **-1.97** | **-1.85** |

60 日收益差 Δ（pp）：生命线 -3.16/-1.44/-7.22/-0.29；阴量线 -3.30/-0.91/-3.51/-1.16；
任一不破 -3.74/-1.72/-5.41/-1.43；全部不破 -3.47/-1.13/-5.52/-1.05。

**判定（照实说）**：
1. **生命线 / 阴量线 / 任一不破 / 全部不破 四条口径，25 日与 60 日的 Δ 在四段几乎全为负**（仅进攻K因 B 组 n=0 无法比）。即「回踩不破=洗盘」组前向收益系统性 **低于**「已破=破位」组。
2. **这不是「无信息量」，而是「方向反了」**：Jeremy 的规则是「回踩不破→买/加仓」，但数据说单针时「回踩不破」的后续收益更差。
3. **机制解释**：单针（短期超卖）语境里，三条线实际测的是「这一跌跌得有多深」——收盘还在线上方（回踩不破）= 跌得浅、还不够超卖；已破线 2 日 = 跌得深、更超卖、反弹更大。这与阶段 12 的发现同源：**深水单针（跌得深）才有正 alpha**，所以「破位」组反弹更强。
4. **进攻K防线在个股上依旧空转**：B 组（已破 2 日）n=0——个股进攻 K 阈值（主板≥10%/创业科创≥20%）太稀，单针时几乎从不 2 日跌破进攻 K 中点。与阶段 13 结论一致：进攻 K 这条线主要在 ETF（≥4%）和「一直没大涨突然大涨」的个股上有效，**不能当普适防线**（报告里明确适用范围）。

### 3.2 2 日容错 vs 单日破即算破（量化容错收益差，25 日 Δ）

| 线 | IS 2日/单日 | OOS-A | OOS-B | OOS-C |
|----|------------|-------|-------|-------|
| 生命线 | -1.67 / -1.87 | -1.26 / -1.19 | -2.57 / -2.56 | -2.00 / -1.83 |
| 阴量线 | -1.72 / -2.01 | -0.89 / -0.96 | -2.09 / -1.30 | -1.81 / -1.83 |
| 任一不破 | -2.16 / -2.34 | -1.53 / -1.44 | -2.85 / -2.61 | -2.13 / -1.82 |

**判定**：2 日容错只把 Δ 挪动 ~0.2~0.8pp，**符号一个都没翻**。容错本身没错（单日破确实太敏感），
但它救不了「三条线方向反了」这个根本问题。

## 4. 诚实声明 / 坑

1. **三条线作为洗盘判别器是负 alpha（反向）**：这是本阶段最硬的一条结论，不是调参能救的。
   根因是「单针=超卖」语境里，线的高低只反映跌得深浅，而不是「洗盘 vs 破位」。
2. **阶段底入场加确认（组2）与阶段13「站上生命线」同病**：任何「等确认」都在买贵，牺牲深水赔率。
   真正稳的正超额仍是**深水单针（探底当天）25/60 日四段全正**（组1）。
3. **完整架构（组3/第四步）的仓位级记账已补上（阶段13 遗留项）**：结论仍是「防守有效、进攻拖累」，
   有效成分是预备队 + 降敞口上限，不是阶段顶择时。
4. **仓位循环口径（写死）**：单股单生命周期（窗口内首个阶段底入场，持有到窗口末）；首笔 3 成；
   加仓=持仓期间单针 + 任一不破（2 日容错），2/2/1 成；阶段顶卖当前仓位 50%。未计交易成本、
   现金零收益、未做停牌/涨跌停约束。
5. **幸存者/前视**：与阶段 11/12/13 相同，用当前仍上市股票 + 当前行业快照，长持有期反弹会被幸存者偏差高估。
6. **N 档选择**：柱状阶段顶底 N=5/10 都能复现 159828 全部标注；N=20 太慢（吞掉 3/25）。主口径 N=5。
