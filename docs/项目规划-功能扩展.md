## 四大功能块

### 1. 板块资金（v1 已做）
- `/sectors` 页：窗口切换（即时/3/5/10/20日）+ Top20 流入/流出
- 数据源：同花顺 `stock_fund_flow_industry`（scripts/fetch_sector_flow.py → data/sector_flow.json）
- 待补：① 信号标签（连续N天净流出→可建仓、MACD底背离）② 成分股排行 + ETF ③ 同花顺行业→申万板块名称映射

### 2. 个股推荐（战法信号，待做）
- 把战法信号挂到板块成分股上：点进某板块 → 看它每只成分股触发了哪些信号
- 战法清单（全部已在 packages 实现，待接 API + 前端）：
  - **B1 / B2 / 单针 / 暴跌 / MACD底背离** → 现有 6 策略 + divergence 模块（已有 /strategies 接口）
  - **生命线** → stage13.lifeline_value（=(顶背离区间最高+底背离区间最低)/2）
  - **阴量定价线** → stage14.yin_volume_line_series（顶背离附近量最大阴线的最高价）
  - **进攻K** → stage13/14 attack_defense（中点+跳空用最低价+栈逻辑）
- 缺口：生命线/阴量定价线/进攻K 未在 API（现有 indicators 只有 MACD/KDJ/RSI/量能）

### 3. 最新消息（财经日报式，待做）
- 宏观消息卡片流：每条 = 标题 + 影响评级（改变定价/P1显著影响/P2结构性关注）+ 未来导向 + 来源数
- 参考：每日复盘/html/照片 的财经日报长图
- 数据源：现有财经快讯 cron（金十数据）

### 4. 事件日历（关键会议 + 财报，待做）
- FOMC、CPI、非农、央行会议、重要财报日期
- 需要单独建结构化数据源（现有快讯无结构化的日历）
