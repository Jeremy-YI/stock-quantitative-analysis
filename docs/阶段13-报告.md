| 块 | 结果 |

口径实现（`indicators/stage13.py`）：
- 区间化摆动点 `swing_highs/swing_lows`（k=3），锚点 = 窗口极值，确认日 = pivot + k（无前视）。
- 底背离 = 摆动低点 + **收盘价创新低**（不破底用收盘价）；顶背离 = 紧邻低点之前的摆动高点。
- 生命线 = (顶背离区间最高 + 底背离区间最低) / 2。
- 进攻 K 中点 = (开盘 + 收盘) / 2（已用 159828 的 6/29=3.775 验证，不是 (高+低)/2=3.75）。
- 进攻 K 栈逻辑：当前有效 = 最近一个未被收盘跌破中点的进攻 K；破了出栈回退。

## 3. 第三步：长上影线卖出（新口径已入场样本）

规则：持仓期间首次出现「上影线长度 ÷ (高-低) ≥ 阈值」→ 卖 X% 仓位（50/70/100%），
其余按原双防线走到离场。表格 = 平均收益% / MAE% (n)。

| 段 | base 收益/MAE | 卖50% | 卖100% | 结论 |
|----|--------------|-------|--------|------|
| IS | -6.85 / -19.2 | -4.02 / -5.2 | -0.42 / -5.2 | 熊市救命 |
| OOS-A | +1.00 / -12.2 | +0.61 / -3.7 | +0.25 / -3.7 | 收益小亏、回撤大降 |

| OOS-C | +8.47 / -9.9 | +4.70 / -3.4 | +0.85 / -3.4 | 牛市砍掉大半 |

（阈值 50% 档；60%/70% 档趋势相同，阈值越高触发越少、破坏越小。）

**判定**：长上影线卖出把 MAE 四段砍掉 6~14pp（达标），但牛市收益也被砍掉一半以上
（OOS-C 卖 100% 时 +8.47%→+0.85%）。**纯防守工具**：下跌/震荡年划算，上涨年不划算，
和阶段 12 仓位状态机、12b 止损同一个结论。且阈值 50% 触发极频繁（约 91% 持仓踩到），
实操若要用应取 60~70% 档 + 卖 50%（而非全卖）。

## 4. 诚实声明 / 坑

1. **「顶背离」在生命线语境里是「摆动高点」不是 MACD 顶背离**：159828 的 3/17（4.27）与
   5/21（4.17）都是**下降趋势中的 lower high**，DIF 也随之走低，不构成经典 MACD 顶背离。
   生命线锚点只需摆动点（k=3）就能复现，MACD 背离只在**底背离的增量资金**（绿柱变浅）里作为确认。
   这点与 Jeremy「顶背离」字面含义有出入，已在实现里按「摆动高点」处理，未凑 MACD。
2. **底背离 = 收盘创新低的摆动低点**：用收盘价判断「不破底」（6/22 盘中破 3.59、收盘 3.72 不算破）。
   这个口径复现了 3/23、6/09 两个锚点，且天然排除了 6/29（更高低点）这类「假底」。
3. **进攻 K 中点对个股基本不触发**：主板 ≥10%/创业科创 ≥20% 太稀，第二道防线在个股回测里≈空转。
   这套双防线主要在 ETF（≥4%）上才有第二道的信息量；个股的防守主要是第一道生命线。
4. **前视/幸存者**：与阶段 11/12 相同，用的是当前仍上市股票 + 当前行业快照，长持有期反弹会被幸存者偏差高估。
5. **双防线未做部分仓位记账**：生命线「减仓」在本回测里只做事件标记（破线/洗盘），收益按满仓到
   真正离场算，未把「减仓 50%」的现金流折进收益。要精确需再做仓位级模拟，留待后续。
