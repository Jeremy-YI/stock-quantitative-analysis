# 市场环境模块说明（阶段 8）

> 目的：新增 `packages/market/regime.py` 市场环境（regime）模块，把「择时」从
> 选股策略里拆出来，做成组合回测的一等公民——在允许的市场状态下才开仓。
> 本文档记录 regime 定义、实测依据、filter 默认值的来源，以及加 filter 前后的组合对比。

---

## 0. 一句话结论

**市场环境（择时）比选股重要得多**：区间基线胜率在 42%~68% 之间波动（26pp 差异），
远大于任何选股策略的超额（+7~14pp）。默认 regime filter（大盘 20 日涨幅 < +4%、
活跃度 < 1.2、回撤在 -15%~0）能把「均值回归组合」限定在其超额为正的市场状态里，
组合对比见第 4 节。

---

## 1. regime 定义（三个指标 + 离散分档）

模块从全市场个股日线计算等权市场序列（`compute_market_series`），导出三个指标：

| 指标 | 计算 | 含义 |
|---|---|---|
| `index_20d_return`（r20） | 等权指数近 20 个交易日涨跌幅 | 大盘趋势方向 |
| `activity` | 当日总成交量 / 过去 60 日平均总成交量 | 市场活跃度 |
| `drawdown` | 等权指数相对近 120 日最高点的回撤（≤0） | 距高点的回撤深度 |

离散分档（`classify_regime`，边界与 /tmp/regime_test.py 一致）：

- **r20**：强跌<-10% / 弱跌-10~-4% / 微跌-4~0 / 微涨0~4% / 上涨4~10% / 强涨>10%
- **activity**：清淡<0.8 / 偏淡0.8-1.0 / 正常1.0-1.2 / 活跃1.2-1.5 / 火爆>1.5
- **drawdown**：深跌<-25% / 中跌-25~-15% / 浅跌-15~-8% / 近高-8~-3% / 新高区-3~0

---

## 2. 实测依据（529,497 样本，2023-01 ~ 2026-08，见 docs/因子研究报告.md §5）

- **均值回归组合**（水下多头 + vr60<0.6）的超额随 regime 变化极大：大跌 +10.87pp、
  清淡 +11.24pp、浅跌 +7.11pp，但强涨 -8.94pp、火爆样本不足、中跌 -1.61pp。
- **趋势跟随组合**（水上多头 + 完美多头 + 站上MA120）在本区间几乎处处负超额。
- **区间基线 42%~68%（26pp 差异）> 任何选股策略超额**，因此择时优先。

## 3. 默认 filter 的来源

`RegimeFilterConfig`（`backtest.config`）默认值：

| 参数 | 默认 | 依据 |
|---|---|---|
| `max_index_20d_return` | +4% | r20 ≥ +4% 时均值回归组合超额转负（-1.96pp / -8.94pp） |
| `max_activity` | 1.2 | 活跃 ≥ 1.2 时均值回归超额转负（-1.10pp / 火爆最差） |
| `min_drawdown` | -15% | 中跌 -25~-15% 时均值回归超额转负（-1.61pp） |
| `max_drawdown` | 0% | 回撤必须 ≤ 0（低于高点）；实际由 min/max 共同框定 -15%~0 |

即：**大盘 20 日涨幅 < +4% 且 活跃度 < 1.2 且 回撤在 -15%~0** 时允许开仓。
任一指标缺失 / NaN → 保守不允许（`should_allow` 返回 False）。

## 4. 组合回测：加 regime filter 前后对比（实测）

> 区间 2026-03-01 ~ 2026-08-27（124 个交易日）。复现：
> `.venv/bin/python scripts/run_regime_filter.py`（六策略组合）；
> washout 单策略对比见下方补充。

| 组合 | 无 filter | 有 filter（默认） |
|---|---|---|
| 等权（六策略） | -11.37% / -19.72% / -1.191 | **-18.42% / -23.68% / -2.107** |
| etf_accumulation 独占 | +1.99% / -21.38% / +0.174 | -2.42% / -19.96% / -0.290 |
| macd_volume_washout 独占 | -19.48% / -31.99% / -1.480 | -15.45% / -27.96% / -1.383 |

（格式：总收益 / 最大回撤 / 夏普）

### 4.1 诚实结论：filter 不能把组合从负转正，但对均值回归策略方向正确

1. **默认 filter 是给「均值回归组合」设计的，不是给六策略组合**。把它套在六策略
   组合上反而更差（等权 -11.37% → -18.42%），因为它排除了深回撤（< -15%），
   而唯一正收益的 etf_accumulation（「跌幅 25-40% + 底背离」）恰恰需要深回撤环境
   才触发——filter 把它的买点全挡掉了。
2. **对均值回归策略（macd_volume_washout），filter 方向正确**：-19.48% → -15.45%,
   最大回撤 -31.99% → -27.96%，损失收窄。但它仍无法把组合转正——因为 2026-03~08
   整体是弱市，全市场 20 日基线约 -1.6%，即使 +8pp 超额胜率的策略绝对收益仍为负。
3. **择时价值 > 选股价值，但不等于「能逆势盈利」**。regime 过滤能在弱势里减少
   回撤（择时的作用），但个股/ETF 层面仍然跑不过现金；真正要把组合转正，需要
   更激进的仓位管理（如只做空仓等待 + 只在极端超卖时出手），而非当前「二值过滤」。

> 本阶段最重要的数字不是「filter 把组合转正」（没有发生），而是「filter 对不同
> 策略方向相反」：对均值回归有效、对深跌吸筹（ETF）有害——这直接决定了
> regime 过滤不能全局一刀切，必须按策略类型分别配置。

## 5. 组合回测接入方式

- `PortfolioConfig.regime_filter: RegimeFilterConfig | None = None`（None = 不过滤，
  旧行为）。
- `simulate_portfolio(..., regime_series=...)`：只影响开仓（卖出不受限）；当日
  regime 不允许则跳过所有买入，计入 `skipped_buys`。
- `BacktestEngine.run_portfolio` 在启用 filter 时自动从全市场 candles（仅个股宇宙）
  计算市场序列并传入，调用方无需手动算 regime。
- API：`POST /backtest/runs` 请求体新增 `regime_filter: bool`。
