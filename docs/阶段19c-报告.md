# 阶段 19c 报告：Jeremy 活跃市值切换策略——全周期回测

> 策略：活跃市值(OAMV) 择时，在「资金流入板块（成长）」与「红利低波（防守）」之间切换。
> 本报告用 Jeremy 口述的 **20 笔半导体买卖日期**（卖后切红利低波）做全周期回测。

---

## 摘要（结论先行）

1. **策略验证通过，且极强**：2020/10/29 ~ 2026/08/28 累计 **+1640%**（年化 +66%），
   最大回撤 **-25.5%**，夏普 **1.89**，**7 个年度全部为正**，20 笔交易胜率 80%。
2. **核心 alpha 是「择时」，不是「选股」**：把成长篮子换成任何板块（能源金属/电池/元件/设备等），
   用同样的切换日期都能拿到 +500%~+1900%。甚至「一直持有仅 +21%」的医药，切换后也 +692%（33 倍）。
3. **基准要摆对**：散户不会「一直持有」6 年，3 个月~1 年已是极限。真正的对照是
   上证指数 +28%、红利低波 +46%——切换策略分别跑赢 **58 倍 / 35 倍**。
4. **机械化现状**：活跃市值数据无法程序化获取（指南针 WebSocket 推送，本地无文件、无 HTTP 接口），
   已用「流通市值 × 站上MA250」代理做每日告警（阈值放大粗筛，触发提醒 Jeremy 人工确认）。

## 2 板块敏感性：成长篮子换成各板块（同样 20 笔切换日期）

| 板块 | 切换累计 | 一直持有 |
|---|---|---|
| 能源金属 | +1887% | +204% |
| 半导体 | +1640% | +178% |
| 电池 | +1438% | +83% |
| 小金属 | +1222% | +297% |
| 电子化学品 | +1201% | +191% |
| 自动化设备 | +1164% | +96% |
| 元件 | +589% | +204% |
| 光学光电子 | +531% | +74% |
| 消费电子 | +461% | +59% |
| 贵金属 | +334% | +337% |
| 医疗服务(医药) | +692% | +21% |
| 银行 | +10% | +8% |
| 保险 | +41% | -9% |

**读法**：
- 半导体不是唯一也不是最好，能源金属/电池/小金属/电子化学品/自动化设备都更高 → 成长篮子应动态选「当期资金流入最强板块」。
- 医药「一直持有」仅 +21%（Jeremy 判断正确），但切换也能 +692%（择时抓上涨段）→ **alpha 在择时，不在选板块**。
- 银行/保险/航运垫底（防守板块当成长篮子不行）。

## 3 信号规则（Jeremy 定版）

- **买入（切成长）**：活跃市值单日涨 ≥ +4%，或两天累计 > +4%。
- **卖出（切红利低波）**：活跃市值出现「MACD 阶段性顶部（红柱最高后收缩）」1 次即算，具体表现为：
  ① 单日跌 ≥ -2.3%（一次，不要求两次）；② 连续 3 天顶部上影线（累计 -2.3%）。
- **上影线口径**：上影占 K 线全长 ≥ 60%（沿用 159828 案例口径，待最终确认）。

## 4 机械化与告警

- **活跃市值数据不可程序化获取**：指南针用 WebSocket 实时推送，本地无文件、HTTP 缓存无 K 线接口；
  截屏视觉读 OHLC 误差 ±1%，套 -2.3%/+4% 小阈值会翻车。
- **折中方案**：`scripts/oamv_daily_alert.py` 用「全市场流通市值 × 站上MA250」代理，
  阈值放大（+5%/-5%）粗筛，触发后 cron 投递飞书告警，Jeremy 人工确认后执行。
- **cron**：`活跃市值代理每日告警`，周一~周五 16:00（Asia/Shanghai）。
