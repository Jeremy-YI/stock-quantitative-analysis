# 双底反弹迁移说明（阶段 7）

> 目的：把 Jeremy 的美股双底扫描器 `~/.openclaw/workspace/tools/us_double_bottom.py`
> 迁移进 `packages/strategies/double_bottom/`，适配 A股口径，并补上一致性验证、
> 快照测试、真实回测超额胜率。本文档记录新旧实现差异、参数含义、实测超额。

---

## 0. 一句话结论

双底反弹（W 底）策略 = **双底齐平 + 底背离（DIF 抬升为硬条件）+ 缩量二次探底 +
回撤甜点区**。它属于「埋伏型」选股：在右底构筑/爬升阶段就出手，赌的是抛压衰竭后的
反弹。真实回测（2026-03-01 ~ 08-27，124 个交易日）的实测超额胜率见第 4 节。

## 1. 新旧实现差异

旧脚本 `us_double_bottom.py` 是给美股（yfinance 数据）写的。迁移到 A股时，形态判定
核心逻辑（摆动低点 → 配对左右底 → 颈线 → 底背离 → 量能）**逐行保持一致**，只改了
三处口径，其余交易约束（涨跌停 / T+1 / 复权）下沉到 `packages/backtest`：

| 维度 | 旧脚本（美股） | 新实现（A股） | 理由 |
|---|---|---|---|
| 流动性门槛 | `closes × volume` 近似「美元成交额」，阈值 2000 万美元 | 用 hsjday 自带 `amount`（成交额，元）列，阈值 5000 万元/日 | A股 hsjday 直接有 `amount`，旧脚本的 `closes×volume(手)` 是美股口径的换算错误 |
| 最低股价 | `MIN_PRICE = 5.0` 美元 | `min_price = 5.0` 元 | 语义不变（剔除仙股），单位随市场 |
| 回撤基准 | `max(highs)` 取全窗口（实际拉 2 年 ≈ 2 年高点） | 显式取近 `drawdown_window=250` 个交易日最高点（≈ 1 年） | 旧脚本注释写「1 年高点」但代码用全窗口，与注释不符；新实现按注释意图修正 |
| 交易约束 | 无（美股无涨跌停、T+0） | 涨跌停 / T+1 / 前复权由 `backtest` 的 `execution` / `portfolio` / `market.adjust` 落实 | 策略层只做形态识别，不重复实现交易规则 |

**一致性验证**：把两边流动性门槛都关掉（`min_amount=0` / `min_dollar_vol=0`）后，
新旧在「是否触发信号」上逐标的一致（`tests/unit/test_strategy_consistency.py` 的
`test_double_bottom_selection_matches_legacy*`）。因为回撤基准只影响 score 不影响
选择，流动性口径是唯一会改变选择集合的差异，故关掉流动性后集合必然一致。

**其余差异只影响 score 不影响选择**：回撤甜点区加分（+12/+5）、量能加分项等，新实现
把这些权重提成模块级命名常量（见 `strategy.py` 顶部 `_SCORE_*`），阈值类参数全部
收敛进 `config.py`，逻辑里无裸数字。

## 2. 参数含义（`packages/strategies/double_bottom/config.py`）

| 参数 | 默认 | 含义 / 来源 |
|---|---|---|
| `swing_k` | 6 | 摆动低点左右各需 k 根不低于它（越大低点越显著，旧脚本 SWING_K） |
| `recent` | 12 | 右底必须在最近 N 根内（信号新鲜度，旧脚本 RECENT） |
| `min_gap` / `max_gap` | 12 / 90 | 两底间隔窗口（根），太近不算双底、太远形态失效 |
| `tol_higher` / `tol_lower` | 0.03 / 0.03 | 低点相似度容差：右底 L2 相对左底 L1 在 [-3%, +3%] 内 |
| `min_rally` | 0.12 | 颈线（两底间最高点）相对底部至少抬升 12%（中间要有真实反弹） |
| `l2_low_zone` | 1.05 | 右底 ≤ 近 60 日最低价 × 1.05（右底要落在低位区） |
| `max_above_neck` | 0.15 | 现价超颈线 15% 以上视为形态已走完，剔除 |
| `require_breakout` | False | **颈线突破确认开关**：True 只出「已站上颈线」的确认信号（标准 W 底买点）；False 保留右底构筑/爬升/突破中全阶段（埋伏型，与旧脚本一致） |
| `breakout_margin` | 0.02 | 站上颈线判定：现价 > 颈线 × 1.02 |
| `vol_shrink_threshold` | 0.8 | 右底附近均量 / 左底附近均量 < 0.8 视为缩量二次探底 |
| `vol_window` | 1 | 底部均量半径（idx±1 共 3 根，对应旧脚本 vol_at） |
| `min_price` | 5.0 | 最低股价（元），剔除仙股 |
| `min_amount` | 5e7 | 20 日均成交额下限（元，5000 万），剔除流动性不足 |
| `drawdown_low` / `drawdown_high` | 25 / 40 | 回撤甜点区（%），TOOLS.md「ETF 入场」同款区间逻辑 |
| `drawdown_window` | 250 | 回撤基准：近 N 个交易日最高价（≈ 1 年） |
| `min_bars` | 150 | 最少历史 K 线根数 |

## 3. 目标宇宙

`TARGET_KINDS = (SymbolKind.STOCK,)` —— 只对 **A股个股** 扫描。

理由：双底 + 底背离 + 缩量二次探底是「个股筹码结构」的语言，ETF 内部成分分散、
底背离语义弱（ETF 的 `etf_accumulation` 策略已单独用「跌幅 + 底背离」口径处理，
见 `packages/strategies/etf_accumulation/`），故本策略不覆盖 ETF。

> 区间 2026-03-01 ~ 2026-08-27（124 个交易日），与阶段 4.5 完全同口径：
> 超额胜率 = 策略胜率 − 同期同宇宙（个股）基线胜率，见 docs/回测迁移说明.md。
> 复现：`.venv/bin/python scripts/run_signal_overlay.py --start 2026-03-01 --end 2026-08-27 --jobs 8`。

| 3 日 | 12677 | 40.4% | 45.3% | **-4.9pp** | -0.83% | -0.60% |
| 5 日 | 12664 | 39.2% | 44.1% | **-4.9pp** | -1.24% | -0.82% |

- 日均信号 **102.6 条**（选择性 1.86%），远超 5 条/日的可靠性门槛，不存在「样本太少」
  的问题——**它就是真的没有超额**，且和 macd_resonance 一样「越拿越亏」。
- 结论：**双底反弹实测超额为负，按任务书约定不提高它的权重**，数据已写入
  docs/信号叠加分析.md 并排对比。
